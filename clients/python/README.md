# vernacular-client

Python client for the Vernacular API: human-verified words and phrases in Zambian languages,
each with its trust status and sources.

```bash
pip install vernacular-client
```

```python
from vernacular import Vernacular, VernacularError

with Vernacular(api_key=KEY, base_url=URL) as v:
    for hit in v.search("bem", "amenshi").data:
        print(hit.entry.headword, hit.entry.trust.status)

    pack = v.phrases("greetings", "nya")

    try:
        v.entry("…")
    except VernacularError as e:
        print(e.status, e.code, e.docs_url)
```

Methods: `languages`, `search`, `entry`, `concept`, `lookup`, `phrases`, `translate`, `detect` and
`releases`. Each returns a model generated from the API contract and raises `VernacularError`
when the call fails. Optional parameters, such as `min_status="machine"` or `release="latest"`,
are keyword arguments. Every other endpoint is in `vernacular._api.api`, called with
`client=v.client`.

Only `verified` items come back unless you pass `min_status`. Read the trust fields before you
rely on a word.

## Developing

`vernacular/_api` is generated by `make gen` from `contracts/openapi.yaml`; never edit it. Run the
tests with `uv run --group dev pytest`.
