# Style guides

Reviewers and the normaliser (P1-SRC-03) both follow these rules, so entries from different sources and people look the same (DQ-5).

| File                   | Covers                                                  |
| ---------------------- | ------------------------------------------------------- |
| [common.md](common.md) | Rules for every language: fields, definitions, examples |
| [bem.md](bem.md)       | Bemba (Icibemba)                                        |
| [nya.md](nya.md)       | Nyanja (Cinyanja)                                       |

**Status: draft.** Written from the published orthographies and the SMOL/GATITOS data. Each guide needs sign-off from two senior reviewers for its language (P0-OUT-07) before Phase 1 review starts. Points marked **Decide** are open questions for them.

When a rule changes, record it in the guide's change log with the date and who agreed, because reviewers' earlier decisions were made under the old rule.
