---
title: Phrase packs
description: Ready-made phrases for apps, and how to drop them into your i18n files.
---

A phrase pack is a set of everyday lines on one topic, each with its English source and a
translation checked by reviewers. There are six packs: `greetings`, `numbers`, `dates`,
`interface` (labels such as "Save" and "Cancel"), `health` and `money`.

## Read a pack

```bash
curl -H "X-API-Key: $VERNACULAR_KEY" \
  "$VERNACULAR_URL/v1/phrases?pack=greetings&lang=bem"
```

Each phrase carries its trust fields, like every item. Only `verified` phrases come back unless
you pass `min_status`; see [verification levels](/docs/verification-levels).

## Placeholders

Some lines have placeholders in braces, which your app fills in: `Hello, {name}`, or
`Amount due: K{amount}`. Every translation keeps the same placeholders, though it may move them,
and each phrase lists them in `placeholders`:

```json
{
  "source_en": "{count} new messages",
  "text": "…",
  "placeholders": ["count"],
  "notes": "How the words around {count} change when it is 1"
}
```

Read the `notes` before you build a message: in Zambian languages the words around a placeholder
often change with what fills it, for example to agree with a noun's class, or for one against
many. Translations that drop or rename a placeholder are refused, so you can substitute values
safely.

## Export for your i18n pipeline

`GET /v1/phrases/export` returns the same pack as a localisation file keyed by the English
source. Pick a `format`:

- `json`: a flat object from English to translation, for i18next, FormatJS and the like.
- `po`: a gettext catalogue. Notes become translator comments, and lines with placeholders are
  flagged `python-brace-format`, so `msgfmt --check` catches a translation that loses one.
- `xliff`: an XLIFF 2.0 document. A segment's `state` follows the trust status: `verified` is
  `final`, `reviewed` is `reviewed`, and anything less is `translated`.

```bash
curl -OJ -H "X-API-Key: $VERNACULAR_KEY" \
  "$VERNACULAR_URL/v1/phrases/export?pack=interface&lang=nya&format=po"
```

The file is named `<pack>.<lang>.<format>`. When an English line has more than one translation,
the first is kept, as these formats allow one per line. Add `release` to export a frozen pack;
see [releases](/docs/releases).
