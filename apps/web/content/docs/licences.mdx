## The code

The API and the web app are open source under the
[MIT licence](https://opensource.org/licenses/MIT).

## The data

The dataset will be published under its own open licence. CC BY 4.0 is proposed: anyone may use
it, commercially too, with credit. Until that is final, treat each item's source licence as the
terms that apply.

Every item names its sources and their licences in `trust.sources`. When you show a word, credit
its source the way its licence asks; for CC BY sources, name the source and link its licence.

## What goes in

Only sources that allow open redistribution are published. Each source is registered first, with
its rights holder, licence, permission document and allowed uses. Datasets published for
research only, such as Zambezi Voice and BIG-C, are used to evaluate our work, never published
through the API.

Machine output (`machine`) names the model that produced it. Publishing it openly depends on
each provider's terms, which are still being confirmed, so machine items may be withheld from
the open dataset until they are.

## Machine translation

Translations returned in the `machine` field of `POST /v1/translate` come from our model,
fine-tuned from Google's Gemma. Using them is subject to the Gemma Prohibited Use Policy, as set
out in the [terms of use](/docs/terms#machine-translation).
